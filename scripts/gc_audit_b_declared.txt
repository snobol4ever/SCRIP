# gc_audit_b_declared.txt -- THE PASS-B HOLDER LEDGER (ARCH-GC § 9 RUNG 3, cfo 2026-09-21, CFO-127).
#
# Pass B is the conservative AUDITOR: it scans the territory pass A scans and names every word that points at a
# block pass A did not mark.  It names CANDIDATES, never defects -- a dead word that looks like a heap pointer
# reads identically to a live root -- so every holder it names is either CURED or DECLARED HERE WITH A REASON.
# ⛔ THE COUNT FALLS ONLY BY CURING OR DECLARING, WHICH IS CONDITION 4 OF LON'S GRANT.  A holder that appears in
# a sweep and is not in this file is a RED in test_gate_gc_conservative_auditor_reports_and_cannot_ship.sh.
#
# ⛔ THE KEY IS A SYMBOL NAME AND NEVER AN OFFSET.  The auditor prints `<module>+0x<offset>` because an offset is
# what it can know at the instant of the finding; the GATE resolves that offset through `nm -S` on the very .so
# that produced it.  An offset is a fact about one build and goes stale on the next; a symbol does not.
#
# FIELDS: <holder-symbol>  <OPEN|DECLARED>  <row or reason>
# OPEN     = a real candidate with a row against it.  The auditor retires when NO OPEN row remains and a sweep
#            finds nothing -- and on that day the gate's expiry arm REDS and says DELETE, because a disabled
#            auditor is a conservative scan wearing an if.
# DECLARED = measured not to be a lost root, with the measurement or the ruling that says so.
#
